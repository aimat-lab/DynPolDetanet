# Accelerating dynamic polarizability calculations of organic molecules using equivariant graph neural networks

Houssam Metni, Maria Kraus, Marie Louise Schubert, Marjan Krstić, Carsten Rockstuhl, Pascal Friederich

Code for predicting the dynamic polarizability tensor of organic molecules with an equivariant graph neural network (an extension of DetaNet).

## Data and model weights

The datasets and trained weights are not in this repository. They will be on Zenodo (link to be added). Place them as follows:
